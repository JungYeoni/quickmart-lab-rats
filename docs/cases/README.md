# 사례 카탈로그

| 사례 | 난이도 | 권장 조 | 핵심 질문 |
|---|---|---|---|
| ① 배민 최소주문금액바 | ★★ | 실험 입문 | 메인이 안 움직인 실험은 실패인가? |
| ② 토스 푸시 디타게팅 | ★★★ | 통계 탄탄 | CTR이 오른 건 더 눌러서인가, 덜 보내서인가? |
| ③ 당근 거래후기·실험 플랫폼 | ★★→★★★ | 데이터 의심하기 | 이 결과를 믿어도 되는가? |
| ④ Netflix 인터리빙 | ★★★★ | ML·통계 배경 | 사용자가 더 선호하는 추천이 사업에도 좋은가? |

운영: 사례당 최대 2개 조, 4개 사례가 모두 1개 조 이상 선택되도록 강사 화면에서 제한(classes.max_teams_per_case).
